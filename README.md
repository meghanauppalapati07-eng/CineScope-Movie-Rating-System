# CineScope – Movie Rating and Recommendation System

CineScope is a Python and Streamlit project for exploring movies, viewing rating information, discovering movies with similar genres, and submitting ratings and reviews.

## Features

- Movie discovery with title search, genre filtering, and sorting
- Movie rating summaries based on the available MovieLens dataset
- Similar-movie recommendations based on shared genres
- User registration and login backed by MySQL
- User-submitted movie ratings and reviews stored in MySQL
- Movie poster lookup through the TMDB API, with a title-based fallback when an image is unavailable (in the optimized application version)
- Rating and genre analytics

> Feature note: Verify each feature in the exact application file you choose to publish and demo. The project folder contains multiple development versions; `datasets/CineScope_Fast_Optimized.py` is the selected entry point in this README because that is the version used in the recent run instructions.

## Technology Stack

- Python
- Streamlit
- Pandas
- MySQL and `mysql-connector-python`
- Requests
- Pillow (used for local image/placeholder handling, if imported by the selected app)
- TMDB API for movie poster metadata/images
- MovieLens dataset for the original movie and ratings data

## Prerequisites

1. Python 3.10 or newer (use the Python version tested on your machine).
2. MySQL Server running locally or on a reachable database host.
3. A MySQL database named `movie_rating_db` with the tables expected by the application.
4. A TMDB API key if you want to fetch real poster images. The application can use its fallback design where a poster is unavailable, if supported by the selected version.

## Setup on Windows PowerShell

Open PowerShell in the project root folder.

### 1. Install dependencies

```powershell
py -m pip install -r requirements.txt
```

### 2. Configure environment variables

Set these values in the same terminal session used to launch Streamlit. Do not put real credentials in source code or commit them to GitHub.

```powershell
$env:DB_HOST = "localhost"
$env:DB_USER = "root"
$env:DB_PASSWORD = Read-Host "Enter MySQL password"
$env:TMDB_API_KEY = Read-Host "Enter TMDB API key (v3)"
```

### 3. Start the application

```powershell
py -m streamlit run datasets/CineScope_Fast_Optimized.py --server.port 8502
```

Then open `http://localhost:8502` in your browser.

## Database

The application expects a MySQL database named `movie_rating_db`. Check `database.py`, `datasets/db_config.py`, and `datasets/auth.py` to confirm the exact schema and table names before running the setup on another computer. Do not upload database dumps or real user records to a public repository.

## MovieLens Dataset

Download the MovieLens dataset separately from the official GroupLens source and place the required CSV files in the local `datasets` folder. The `.gitignore` file excludes `movies.csv` and `ratings.csv` from Git commits. Follow the dataset's current license and redistribution terms.

## TMDB Attribution

CineScope uses TMDB for movie metadata and poster images. Follow TMDB's current API terms and attribution requirements in the application and project documentation. A poster fallback generated by CineScope is not the original movie artwork.

## Security Checklist Before Publishing

- Keep `.env`, `.streamlit/secrets.toml`, passwords, API keys, and tokens out of Git.
- Rotate any credential that has previously been shared publicly or in chat.
- Keep MovieLens CSV files, local poster collections, SQL dumps, and personal user records out of the public repository.
- Review every staged file before committing and pushing.
- Do not publish a live database password or API key in screenshots, documentation, or source code.
